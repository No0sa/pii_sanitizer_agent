\# Reproduction Guide

Follow these steps to run the **Agentic PII Sanitizer** baseline, evaluation, and agent pipeline from a clean environment.

---

## Prerequisites

* **Flutter SDK:** `>=3.19.0`
* **Dart SDK:** `>=3.3.0`
* **Target Operating Systems:** macOS, Windows, Linux, or Web
* **API Key:** Google Gemini API Key (Gemini 2.5 Flash access)

---
